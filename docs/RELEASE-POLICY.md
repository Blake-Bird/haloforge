# Release policy

## Pre-release status

HaloForge is not release-approved. Passing automated tests demonstrates only the covered contracts; it does not establish independent numerical validation, empirical-fit applicability, accessibility conformance, security review, or teaching effectiveness.

## License decision required

No open-source `LICENSE` file has been selected or added. A repository is all-rights-reserved by default, so the rights holder must choose and review a license before inviting public reuse or accepting outside contributions. The choice affects code, documentation, generated figures, bundled assets, and contributor terms.

## Required evidence before a public release

- Independent reference comparisons and frozen numerical benchmark tables with predeclared tolerances.
- A scientific review of every empirical calibration and all EDE-supported claims.
- Accessibility testing across keyboard, screen reader, contrast, reduced motion, and responsive layouts.
- A threat model and security review for any authenticated sharing or hosted storage.
- A human review of provenance, citations, schema migration, import integrity, backup, deletion, retention, and quota behavior.
- A tagged release with release notes, image digest, dependency audit results, and the chosen license.
